🚀 Full-Stack CRUD App with Django, React & REST API
This is a simple full-stack CRUD (Create, Read, Update, Delete) application built using:

Django + Django REST Framework for the backend

React for the frontend

REST API for communication between the frontend and backend


🛠️ Tech Stack
Backend: Django, Django REST Framework

Frontend: React

API: RESTful API for seamless integration

📌 About the Project
This project is a great starting point for anyone looking to build and understand full-stack web applications. It demonstrates how to:

Set up Django with Django REST Framework

Build a frontend with React

Connect frontend and backend using REST API

Perform basic CRUD operations
